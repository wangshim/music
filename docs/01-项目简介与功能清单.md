# 01 - 项目简介与功能清单

## 项目简介

**音频分析助手（Audio Analyzer App）** 是一个 Flutter 跨平台应用（当前以 Android 为主，iOS 工程已生成、未深度适配），定位为**本地自用**工具。

核心能力：用户选择本地音频文件 → App 自动完成**识曲 + 歌词匹配**，直接展示**纯文本歌词（不带时间轴）**；识曲或拉歌词失败时，提供**回退到本地离线语音转写（ASR）**的入口。识曲匹配结果（歌曲名/歌手）仅在 App 内部用于匹配歌词，**不向用户展示**。

设计原则：

- 音频在本地完成指纹提取（16k 单声道 WAV → Shazam 音频指纹）。
- 识曲 / 歌词匹配需联网（Shazam API + lrclib.net，本地自用允许联网）；ASR 兜底全程离线推理。
- 界面 / 歌词 / 转写结果统一简体中文。
- 面向非技术用户：安装 APK 后选择音频即可使用，无需配置。

## 识别流程（识曲 + 歌词）

```
选择音频
  └─> 原生解码（任意格式 -> 16kHz 单声道 WAV）
        └─> Shazam 音频指纹（Dart 实现，参考 shazamio）
              ├─ 成功 ─> lrclib.net 拉取歌词
              │            ├─ 成功 ─> 剥离时间轴 -> 繁转简 -> 展示纯文本歌词
              │            └─ 失败 ─> 中文错误提示
              └─ 失败 ─> 中文错误提示
                          └─ 用户点击"回退到语音转写" -> 本地 sherpa-onnx ASR 转写
```
