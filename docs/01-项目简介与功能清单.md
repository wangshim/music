# 01 - 项目简介与功能清单

## 项目简介

**音频分析助手（Audio Analyzer App）** 是一个 Flutter 跨平台应用（当前以 Android 为主，iOS 工程已生成、未深度适配），定位为**本地自用**工具。

核心能力：用户选择本地音频文件 → App 在本机完成分析 → 展示结果。当前已实现**离线中文语音转写（ASR）**；BPM / 调性分析为结果页占位；识曲 + 歌词功能为规划中（见下）。

设计原则：

- 音频文件不离开本机（ASR 全程离线推理）。
- 界面 / 转写结果统一简体中文。
- 面向非技术用户：安装 APK 后选择音频即可使用，无需配置。

## 功能清单

### 已实现功能

| 功能 | 状态 | 入口 | 核心实现文件 | 说明 |
|---|---|---|---|---|
| 音频选择与试听 | ✅ 已实现 | 首页"选择音频"按钮 | `lib/pages/home_page.dart` | 使用 `file_picker` 选择本地音频，`just_audio` 支持播放试听 |
| 离线中文语音转写（ASR） | ✅ 已实现 | 首页选择音频后进入分析页 | `lib/pages/analyzing_page.dart`、`lib/services/asr_service.dart`、`lib/services/audio_decoder.dart`、`android/.../MainActivity.kt`、`ios/Runner/AppDelegate.swift` | 基于 `sherpa_onnx` 流式 Zipformer 中文模型（int8），手机本地解码音频 → 16kHz 单声道 WAV → 分块转写 |
| 结果展示 | ✅ 已实现 | 转写完成后进入结果页 | `lib/pages/result_page.dart`、`lib/models/analysis_result.dart` | 展示转写文字、耗时、模型信息；BPM / 调性为占位卡片 |
| ASR 模型自动解包 | ✅ 已实现 | App 启动初始化 | `lib/services/asr_service.dart` | `rootBundle` 将 assets 内模型解压到应用可写目录后加载（Android 无法直接读 assets 路径） |

## 页面结构

| 页面 | 文件 | 职责 |
|---|---|---|
| 首页 | `lib/pages/home_page.dart` | 选择音频、试听、进入分析 |
| 分析中 | `lib/pages/analyzing_page.dart` | 调 ASR 转写并展示进度 |
| 结果页 | `lib/pages/result_page.dart` | 展示转写结果 / BPM / 调性 / 模型信息 |

|---|---|
| `file_picker` ^12.0.0 | 选择本地音频文件 |
