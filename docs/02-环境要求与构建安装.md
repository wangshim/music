# 02 - 环境要求与构建安装

## 环境要求

### 必装（开发机）

| 组件 | 版本要求 | 本项目实际路径（Windows） | 说明 |
|---|---|---|---|
| Flutter SDK | 3.47.0 stable | `F:\flutter` | 含 Dart 3.13.0 |
| Android SDK | 37（含 platform-tools） | `F:\Android\Sdk` | 构建 Android APK 需要 |
| JDK | OpenJDK 25（Android Studio JBR） | `F:\AndroidStudio\jbr` | **不要用 Java 11**，与 Gradle 9.3.1 不兼容 |

### 可选

| 组件 | 说明 |
|---|---|
| Android Studio | 2026.1.3.8，用于 Android 工程管理与模拟器（`F:\AndroidStudio`） |
| 真机 / 模拟器 | 安装 APK 与运行验证需要；建议 arm64-v8a 架构手机 |

> Windows 上若本机 `JAVA_HOME` 指向 Java 11，构建时必须显式切换为 JBR：
> `$env:JAVA_HOME="F:\AndroidStudio\jbr"`

## 构建 APK

```powershell
cd F:\audio_analyzer_app
$env:JAVA_HOME="F:\AndroidStudio\jbr"          # 必须，避免 Java 11 冲突

# 安装依赖
flutter pub get

# release 构建（按 CPU 架构拆分，产出 3 个 APK，体积更小）
flutter build apk --release --split-per-abi
```

产出位置：

| 包 | 路径 | 适用设备 |
|---|---|---|
| arm64-v8a | `build\app\outputs\flutter-apk\app-arm64-v8a-release.apk` | 主流 Android 手机（推荐） |
| armeabi-v7a | `build\app\outputs\flutter-apk\app-armeabi-v7a-release.apk` | 老旧 32 位设备 |
| x86_64 | `build\app\outputs\flutter-apk\app-x86_64-release.apk` | 模拟器 / x86 设备 |

也可以构建单个通用包：

```powershell
flutter build apk --release
# 产出 build\app\outputs\flutter-apk\app-release.apk
```

## 安装到手机

```powershell
# 1. 手机开启"开发者选项 + USB 调试"，连接电脑
F:\Android\Sdk\platform-tools\adb.exe devices        # 确认设备已连接

# 2. 安装（arm64 手机推荐）
F:\Android\Sdk\platform-tools\adb.exe install -r build\app\outputs\flutter-apk\app-arm64-v8a-release.apk

# 3. 手机桌面打开"音频分析助手"，选择音频 → 自动识曲并展示纯文本歌词（失败可回退语音转写）
```

> 首次转写时 App 会把 ASR 模型（约 228MB）从安装包解压到应用缓存目录，属正常现象，请稍等片刻（后续复用，不再重复解压）。
> 识曲与歌词匹配需要联网（Shazam API + lrclib.net）；ASR 兜底转写为纯本地离线推理。

## 常见问题

| 问题 | 处理 |
|---|---|
| 构建报 `Could not close incremental caches / Storage is already registered` | Windows 上 Kotlin 增量编译缓存损坏，本项目已在 `android/gradle.properties` 配置 `kotlin.incremental=false` + `kotlin.compiler.execution.strategy=in-process` 规避；如仍出现，执行 `cd android && gradlew.bat --stop` 后重试 |
| `flutter build` 输出被 PowerShell 吞掉 | 用 `cmd /c "cd /d F:\audio_analyzer_app && flutter.bat build apk --release > build.log 2>&1"` 重定向日志查看 |
| `adb devices` 为空 | 手机未开 USB 调试 / 驱动未装 / 换数据线；本项目环境 adb 位于 `F:\Android\Sdk\platform-tools\adb.exe` |
| ASR 转写结果乱码或为空 | 请确认音频为人声清晰、无伴奏或低伴奏的录音；带伴奏歌曲转写效果差是模型预期限制 |
