# 03 - 模型说明

## ASR 模型

| 项 | 值 |
|---|---|
| 模型名称 | sherpa-onnx-streaming-zipformer-zh-14M-2023-02-23（流式 Zipformer 中文 14M，int8 量化） |
| 用途 | 离线中文语音转写（ASR），全程本地推理，不上传音频 |
| 推理框架 | sherpa-onnx（Dart 绑定 `sherpa_onnx ^1.13.6`） |

## 模型文件与打包位置

模型文件位于项目 `assets/models/sherpa-onnx-streaming-zipformer-zh-14M-2023-02-23/`：

| 文件 | 大小 | 说明 |
|---|---|---|
| `encoder-epoch-99-avg-1.int8.onnx` | ~20.6 MB | 编码器（int8） |
| `decoder-epoch-99-avg-1.int8.onnx` | ~1.8 MB | 解码器（int8） |
| `joiner-epoch-99-avg-1.int8.onnx` | ~1.7 MB | Joiner（int8） |
| `tokens.txt` | ~50 KB | 词表 |
| `test_wavs/` | <1 MB | 模型自带测试音频 |
| `README.md` / `export-onnx-zh-14M.sh` | 少量 | 模型来源说明与导出脚本 |

合计约 **24 MB**，已随仓库分发（GitHub 单文件限制内，克隆后无需额外下载即可构建）。

## 打包机制

1. `pubspec.yaml` 显式声明上述 4 个模型文件（`assets:` 段），`flutter build` 时打包进 APK 的 `assets/flutter_assets/assets/models/...`。
2. App 启动时 `lib/services/asr_service.dart` 用 `rootBundle.load()` 将模型解压到应用可写目录（`Directory.systemTemp/audio_analyzer_models`），再传给 `sherpa_onnx.OnlineRecognizer`。
   - 原因：Android 上 Flutter assets 位于 APK 内部，不是真实文件路径，C++ 层无法直接读取，必须先解压。
   - 已存在且非空则复用，避免每次启动重复解压。
